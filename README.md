## ୨୧ about

Ever wondered how well your girlfriend, boyfriend, or best friend actually knows you?

This little website lets you put that to the test! Answer questions about yourself and see if your favorite person can guess the right answers.

## ♡ features

- ୨୧ A fun, personal quiz experience
- ♡ Perfect for couples and long-distance relationships
- ୨୧ See how well someone knows you
- ♡ Cute, cozy website aesthetic
- ୨୧ A fun way to learn little things about each other

## ♡ getting started

1. Clone this repository.

   ```bash
   git clone https://github.com/bluenotthecolor/how-well-do-you-know-me.git
   ```

2. Open the project folder.
3. Open `cozy-quiz.html` in your browser.
4. Take the quiz and see how well you know your person!
